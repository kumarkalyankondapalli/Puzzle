
# AI Word Search Puzzle

An interactive AI vocabulary word-search game built using HTML, CSS and JavaScript.

## Features

- 7 x 7 word search puzzle
- Random puzzle generation
- AI-related vocabulary
- Horizontal, vertical and diagonal word selection
- Forward and reverse word selection
- Mouse and touch support
- Timer
- Three hints per game
- Found keywords display
- Progress bar
- New puzzle option
- Top 10 leaderboard
- Local storage score saving
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Target Words

1. BINARY
2. NEURAL
3. ROBOT
4. LOGIC
5. DATA
6. CODE
7. AI

## How to Run

1. Download or clone the project.
2. Open the AI-WORD-SEARCH folder.
3. Open index.html in your browser.
4. Enter your player name.
5. Click Start Playing.
6. Find all seven hidden words.

## Project Structure

AI-WORD-SEARCH/
- index.html
- style.css
- script.js
- README.md

## Leaderboard

The leaderboard stores the top 10 scores using browser Local Storage.

Scores are saved only in the current browser and device. They are not shared between different devices or users.

## GitHub Pages Deployment

1. Create a GitHub account.
2. Create a new repository named AI-WORD-SEARCH.
3. Upload all four project files.
4. Open repository Settings.
5. Select Pages.
6. Under Build and deployment, select Deploy from a branch.
7. Select the main branch and root folder.
8. Click Save.

GitHub Pages will publish your game website.
